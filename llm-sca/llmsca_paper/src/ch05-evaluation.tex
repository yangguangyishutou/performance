\textbf{Measurement Metrics.} We select common measurement metrics that are used in static white-box fingerprinting. Static white-box fingerprinting captures intrinsic weight characteristics, including statistical distributions~\cite{yoon2025intrinsic} (e.g., $L_2$ distances of model tensors~\cite{horwitz2024unsupervised}), directionally invariant terms~\cite{zeng2024huref}, SVD-based spectral signatures~\cite{wang2025ghost}, and matrix-driven homology proofs~\cite{zhang2025matrix}. In addition to these established measures from prior work, we explore complementary discrepancy signals over flattened weight vectors $a,b\in\mathbb{R}^n$:
$$d_{\mathrm{mean\_abs}}(a,b) = \frac{1}{n} \sum_{i=1}^{n} |a_i - b_i|$$
$$d_{\max\_abs}(a,b) = \max_{1 \leq i \leq n} |a_i - b_i|$$
$$d_{\cos}(a,b) = 1 - \mathrm{cos\text{-}sim}(a,b)$$
We further include two \emph{sparse update rates} that report the fraction of coordinates whose change exceeds a threshold. Let $\Delta_i=|a_i-b_i|$ for $i=1,\ldots,n$. The absolute sparse update rate is
$$\mathrm{SUR}_{\mathrm{abs}}(a,b) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}\bigl(\Delta_i > \tau_{\mathrm{abs}}\bigr)$$
with default threshold $\tau_{\mathrm{abs}}=10^{-2}$. For the relative rate, define $r_i = |a_i-b_i| / \max\bigl(|a_i|,|b_i|,\epsilon\bigr)$ and
$$\mathrm{SUR}_{\mathrm{rel}}(a,b) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}\bigl(r_i > \tau_{\mathrm{rel}}\bigr)$$
with defaults $\tau_{\mathrm{rel}}=10^{-2}$ and $\epsilon=10^{-12}$. Here $\mathbf{1}(\cdot)$ denotes the indicator function: it equals $1$ when the condition holds and $0$ otherwise.

\textbf{Accuracy.} To comprehensively evaluate the structural recovery of model lineages, we measure performance at both the edge level and the tree level. Let $\mathcal{T}$ denote the set of all model family trees in our dataset. We define the following two metrics:

\begin{itemize}[leftmargin=*]
    \item \textit{Micro-accuracy}: This metric evaluates the local edge prediction performance. It is defined as the total number of correctly predicted directed edges divided by the total number of ground-truth edges across all evaluated model graphs:
    $$Micro\text{-}acc = \frac{\sum_{T \in \mathcal{T}} |E_{correct}^{(T)}|}{\sum_{T \in \mathcal{T}} |E_{total}^{(T)}|}$$
    \item \textit{Macro-accuracy}: This metric evaluates the global topology reconstruction. It is defined as the ratio of successfully recovered model family trees (where the entire lineage topology and edge directions are perfectly matched) to the total number of model families:
    $$Macro\text{-}acc = \frac{|\{T \in \mathcal{T} \mid T_{recovered} = T_{true}\}|}{|\mathcal{T}|}$$
\end{itemize}

\textbf{Layers.} To address RQ2, we systematically isolate the core structural components within Transformer-based Large Language Models (LLMs). Specifically, we dissect the Multi-Head Attention mechanism and the Feed-Forward Network (FFN). The attention mechanism involves projection weight matrices for the Query ($W_Q$), Key ($W_K$), Value ($W_V$), and Output ($W_O$):
$$Attention(Q,K,V) = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
Furthermore, we evaluate the contribution of the FFN, which typically consists of Multi-Layer Perceptron (MLP) dense layers:
$$FFN(x) = \sigma(x W_1 + b_1) W_2 + b_2$$
where $\sigma$ represents a non-linear activation function. This granular breakdown enables us to systematically evaluate the fingerprinting capacity of various layer combinations and quantify their respective impacts on the effectiveness of lineage detection.

\textbf{Graph Algorithms.} In our experiments, we evaluate and compare several graph construction algorithms to reconstruct the model lineage topology from the computed pairwise distance and directional matrices:

\begin{itemize}[leftmargin=*]
    \item \textit{MoTher}: Following Horwitz et al.~\cite{horwitz2024unsupervised}, we formulate the base lineage recovery task as finding a minimum directed spanning tree (MDST). We employ the Chu-Liu-Edmonds algorithm~\cite{chu1965shortest, edmonds1967optimum} to achieve this optimal cycle-free directed routing.
    \item \textit{Atlas Greedy DAG}: To account for complex, non-tree structures, we evaluate the Model Atlas framework~\cite{horwitz2025we}. This approach constructs a Directed Acyclic Graph (DAG) via a greedy algorithm, leveraging real-world structural priors such as temporal upload dynamics to determine edge directionality and explicitly accommodating multi-parent merged models.
    \item \textit{Strict-Directional MDST}: We introduce a heavily constrained variant of the MDST. By setting the penalty for reverse edges (i.e., edges that violate the inferred directionality constraints) to infinity ($\infty$), we strictly force the algorithm to adhere to the predicted parent-child hierarchical flow.
    \item \textit{Undirected-MST}: We also implement a decoupled baseline. In the first stage, we construct a minimum spanning tree (MST) on the undirected graph using solely the distance matrix to determine topological connectivity. In the second stage, we subsequently assign directions to these established edges based on the independent directional information.
\end{itemize}
