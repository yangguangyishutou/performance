\section{Empirical Results}

We design experiments to explore the following research questions. 

\begin{itemize}[leftmargin=*]
    % Using different distance metrics/direction methods/graph methods to detect lineage
    \item \textbf{Measurement Evaluation (RQ1)}: How do different measurement metrics affect the effectiveness of LLM lineage detection?
    % calculate the contribution of different model layers to the effectiveness of LLM lineage detection
    \item \textbf{Layers in Transformer Block Evaluation (RQ2)}: How do different model layers influence the effectiveness of LLM lineage detection?

    \item \textbf{Failure Analysis (RQ3)}: Why do existing methods fail to detect lineage?

    \item \textbf{Integration (RQ4)}: using the above findings, the best performance can achieve? (80\%)
\end{itemize}
