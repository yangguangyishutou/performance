# Java 强语法约束提取 Prompt v1.0

## 角色

你是 Java 编程语言语法专家，专门提取**强语法约束**用于代码生成模型的 token 剪枝。

## 核心目标

提取**实用主义的语法约束**：

> 当程序员写下某些 token 后，后面**极大概率**（>90%）会跟的语法强制内容

**目的**：在代码生成时，剪枝掉 90%+ 的错误 token 可能性

## 强约束定义

### ✅ 强约束（符合提取标准）

1. **唯一性约束**（1种 consequent）
   - `if` → `(`
   - `while` → `(`
   - `try` → `{`
   - 剪枝率：>99%

2. **少量选择约束**（2-5种 consequent）
   - `return` → `;` 或 `<expression>`
   - 剪枝率：>90%

### ❌ 弱约束（不符合提取标准）

广泛选择约束（>5种 consequent）使用抽象占位符，不枚举。

## 输出格式

```json
{
  "construct": "if...else",
  "language": "java",
  "syntax_node": "if",
  "constraints": [
    {
      "conditional": "if",
      "consequent": "(",
      "skip": "",
      "required": true,
      "note": "if 后必须跟左括号"
    },
    {
      "conditional": "if (",
      "consequent": ")",
      "skip": "expression",
      "required": true,
      "note": "左括号后必须跟右括号"
    }
  ]
}
```

## 占位符

- `[IDENT]` - 标识符
- `[TYPE]` - 类型
- `<expression_start>` - 表达式起始
- `<statement_start>` - 语句起始

## 需要提取的 Java 构造

1. 控制流：if, else, for, while, do...while, switch, case, break, continue, return
2. 异常：try, catch, finally, throw, throws
3. 类：class, interface, enum, extends, implements, new
4. 方法：void, return, (, ), {, }
5. 访问修饰：public, protected, private, static, final, abstract
6. 包：package, import
7. 变量：boolean, int, long, float, double, char, byte, short
8. 其他：synchronized, this, super, instanceof

从 Java 语言规范中提取这些构造的语法约束。
