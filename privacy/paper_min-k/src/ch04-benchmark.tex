\textbf{Members.} We leveraged The Pile~\cite{pile}, a large-scale open-source language modeling dataset composed of multiple smaller datasets, including 7.6\% of a repository dataset sourced from GitHub~\cite{thepile}. The Pile released in 2021, serving as the training dataset for many LLMs, including Pythia\todo{CITE evidence}, GPT-Neo\todo{CITE evidence}, StableM\todo{CITE evidence}, etc.

For Python, we extract Python functions (methods) from the code portion of the Pile dataset using scripts to generate a JSONL file. 

From this file, we systematically sample 30 functions from every 100 consecutive entries starting from the beginning, collecting a total of 3,000 entries to obtain 300 functions, resulting in the positive.jsonl file. 


For Java, we similarly refer to the code portion of the Pile dataset and use scripts to extract 300 Java classes, generating a JSONL file. 

We then employ additional scripts to extract functions from these classes, which serve as our positive samples for the Java dataset.

\textbf{Non-members.} For non-members, we searched GitHub using a customized query on corresponding repositories limiting the creation time after January 2024 of a particular language, either Python of Java. Then, we randomly sample functions (methods) from each repository, selecting between \todo{1 and 30 functions per repository SOME ISSUE WITH 30}. This process yields 300 new functions per programming language, all created after January 2024. To ensure these functions are genuinely original and not cloned from existing sources, we perform verification using three searching heuristics: (1) Searching by the function name; (2) Searching by variable names within each function, and (3) \todo{Searching by function calls within each function}. Two of the authors conducted peer reviews on the searching results to ensure that all 300 functions are original and were created after January 2024.
