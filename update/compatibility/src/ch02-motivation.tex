\subsection{Python Incompatibilities in the Wild}

We focus on incompatible APIs in Python, a widely used language whose issues are representative of modern software ecosystems. The incompatible APIs involve the interaction between the upstream dependencies and the downstream client usages. Given an API evolves from an older version to a newer version, the \textit{forward incompatibility} occurs when the newer version introduces changes that prevent existing client code from running correctly, and the \textit{backward incompatibility} occurs when code written for the newer version cannot run correctly on the older version. The incompatible APIs can introduce substantial development overhead and may result in production failures or service disruptions.
