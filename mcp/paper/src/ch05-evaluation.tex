\textbf{Random Input Samples.} A model's output is often influenced by the context order or the position of samples in the dataset. To prevent the tested model from ``cheating'' by recognizing patterns in the sample sequence, the evaluation program fully shuffles the sample order after loading the JSONL dataset using the \texttt{random.shuffle()} API driven by a random seed. This testing order ensures that the model processes each sample in an independent decision-making environment, eliminating position bias from affecting the experimental results.
