\section{Conclusion}

We present the first dedicated benchmark for evaluating vulnerability detection in MCP servers with regard to five popular vulnerability types in the MCP servers. We construct a paired dataset spanning representative real-world vulnerabilities, including RCE, DoS, SQLi, IFO, and SID. We introduce the matched pair accuracy metric, requiring the detectors to correctly classify both the vulnerable instance and its corresponding fixed version simultaneously. Our experimental results reveal previously overlooked limitations in existing techniques, particularly in their ability to distinguish semantically similar vulnerable and non-vulnerable code. Overall, our benchmark establishes a rigorous and reproducible foundation for assessing MCP server security tools and promotes more robust, semantics-aware vulnerability detection in the LLM supply chain.
