\begin{abstract}
Model Context Protocol (MCP) servers have become essential for connecting large language models (LLMs) with external tools, data sources, and execution environments. While providing lightweight and extensible infrastructure, their privileged access and bridging role introduce significant security risks. To address these threats, various detection techniques—ranging from static analysis and fuzzing to model-assisted approaches—have been proposed. However, their effectiveness remains unclear due to the lack of standardized benchmarks and representative datasets. In this work, we present the first dedicated benchmark for MCP server vulnerability detection, compiling real-world vulnerabilities, categorizing them by type and cause, and constructing reproducible test cases. We define evaluation metrics for accuracy, robustness, generalization, and false positives. Using this benchmark, we evaluate existing detection methods and reveal significant performance gaps, particularly for complex or novel vulnerabilities. Our benchmark establishes a foundation for systematic, reproducible, and MCP-specific security evaluation.
\end{abstract}
